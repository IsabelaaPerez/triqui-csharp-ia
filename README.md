# Triqui (Tic-Tac-Toe) en C# con IA

¡Bienvenido/a a mi proyecto! Este es un juego clásico de Triqui (Tres en Raya) desarrollado completamente en **C#**, diseñado para poner a prueba la lógica de programación y la implementación de algoritmos de toma de decisiones.

## 🚀 Características
*   **Modo Multijugador Local:** Permite la partida clásica de dos personas alternando turnos de forma fluida.
*   **Modo Contra la IA:** Opción de juego individual donde el usuario se enfrenta a un componente de Inteligencia Artificial que analiza el tablero para realizar su jugada.
*   **Validación Automática:** Sistema dinámico que detecta empates, combinaciones ganadoras en filas, columnas y diagonales, bloqueando el juego al finalizar.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** C# (.NET)
*   **Paradigma:** Programación Orientada a Objetos (POO)

## 📁 Estructura del Código Clave
*   Manejo de matrices/arreglos bidimensionales para la representación del tablero en memoria.
*   Lógica condicional optimizada para el escaneo de victorias y bloqueos.
*   Algoritmo de decisión para simular el comportamiento de la IA.
